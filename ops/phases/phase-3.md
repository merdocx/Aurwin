Задача: фаза 3 «Мир» проекта Aurwin.

Прочитай docs/AURWIN_TZ.md, разделы 6.2, А.10.

Реализуй:
- карту 2000x1200 у.е. с пятью именованными зонами из А.10 и их долями;
- плотность рыбы по кормовым зонам с респавном и локальным истощением;
- суточный цикл: внутренние сутки ~3.4 реальных часа, день/ночь по половине,
  ночные модификаторы восприятия и доступности рыбы (7.10);
- движение существ со скоростями из А.10, отражение от границ карты;
- пространственный индекс для поиска соседей в радиусе восприятия
  (он понадобится в фазе 4 и определяет производительность — цель 5).

Тесты: рыба восстанавливается до потолка и истощается локально; существо
не покидает карту; ночью радиус восприятия уменьшается согласно константам.

Гейт: npm test зелёный.

По завершении: отчёт в ops/reports/phase-3.md.
