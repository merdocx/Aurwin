Задача: фаза 6 «Сознание» проекта Aurwin. С этой фазы начинаются реальные траты по ключу.

Прочитай docs/AURWIN_TZ.md, разделы 7.3, 7.6, 7.8.6, А.5.

Реализуй reflection-worker:
- очередь рефлексий, обработка строго вне тикового цикла;
- фоновая рефлексия раз в 24 реальных часа, привязанная к моменту сна существа
  (7.10), через Batch API;
- событийная рефлексия с дебаунсом 4 ч на существо, слиянием событий окна
  и глобальными лимитами 30/час И 120/сутки;
- промпт-кэширование общей системной части;
- модели: Haiku для фоновой, Sonnet для событийной (сверить актуальные ID
  и цены в документации Anthropic перед реализацией);
- контракт вход/выход строго по А.5, включая bonds, aversions, habits, skills,
  signal_history, was_deceived_by;
- применение результата: дельты черт с clamp ±0.1 и пожизненным коридором ±0.6,
  дельты весов ±0.05 с коридором ±0.3, намерения, narrative, narrative_facts;
- обработка смерти с «висящей» рефлексией: результат отбрасывается, текст
  сохраняется как «последняя мысль»;
- деградация при недоступности API: симуляция не замедляется, очередь копится
  с экспоненциальными ретраями, пропущенные сутки не навёрстываются кратно;
- валидация выхода: JSON-схема, длина narrative, диапазоны дельт, белый список
  эффектов, ссылки только на существующие ID;
- ЧЕСТНОСТЬ ПОВЕСТВОВАНИЯ (7.8.6): системный промпт запрещает описывать события,
  отсутствующие во входных данных. Добавь тест, сверяющий narrative_facts
  с журналами signals/episodes/world_events.

Перед первым боевым запуском убедись, что ANTHROPIC_API_KEY читается из окружения
и нигде не логируется.

Гейт: интеграционный тест на 5–10 существах — полный цикл эпизод -> рефлексия ->
изменение поведения; тест деградации при недоступном API; тест честности
повествования.

По завершении: отчёт в ops/reports/phase-6.md, включая фактическую стоимость
тестовых прогонов.
