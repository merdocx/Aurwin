Задача: фаза 4 «Жизнь» проекта Aurwin. Самая большая фаза — не торопись.

Прочитай docs/AURWIN_TZ.md, разделы 6.2, 7.4, 7.7, 7.8, 7.9, 7.10, А.3, А.4, А.9, А.10.

Реализуй:
- тик-пайплайн по А.3 (все 14 шагов, визуальный тик 2 сек, биочасы x7);
- utility AI по А.4 со всеми слагаемыми, включая навыки и привычки;
  веса индивидуальны для каждой особи (7.7); факторы решения пишутся
  в decision_log с семплингом из А.2;
- охота по вероятностной модели А.10 со всеми модификаторами и влиянием навыка;
- размножение по 7.4: разнополость, возрастная стадия, запрет инбридинга
  на глубину 2 поколений;
- возрастные стадии по А.10, включая неэффективное самокормление детёнышей (x0.3);
- механики развития поведения 7.7: рост и затухание навыков, личные оценки зон,
  социальное обучение, вертикальную передачу знаний (взвешивание авторитетностью
  источника, transmission_depth);
- сигнальную систему 7.8: разделение истинного и воспринимаемого состояния,
  display_vigor / alarm_call / stealth_approach, выбор цели касаткой по
  воспринимаемой бодрости, кредит доверия, черта expressiveness;
- родство и кооперацию 7.9: guard_offspring, provision, coordinate_hunt;
  навык parenting должен реально использоваться этими действиями;
- сон 7.10: давление сна, действие sleep, хронотип, полусон касаток,
  пробуждение по alarm_call, штрафы усталости;
- метрики: поведенческая дивергенция когорт, сигнальная система, традиции
  (доля эпизодов с transmission_depth >= 2), сон.

КРИТИЧНО по 7.8: не создавай действие «обмануть» и не помечай сигнал как ложный
в момент подачи. Сигнал — обычное действие в формуле U(a). Лживость вычисляется
постфактум. Если возникнет соблазн добавить флаг is_deceptive — это ошибка
проектирования, напиши об этом в ops/DEVIATIONS.md вместо реализации.

LLM-рефлексию НЕ подключай: заглушка, возвращающая фиксированные намерения.
Настоящая рефлексия — фаза 6. Дрейф весов через рефлексию тоже отложи,
но структуру данных под него заложи.

Обязательно: `npm run simulate -- --days 30 --fast` — прогон без задержек
реального времени, с отчётом по популяции, дисперсии черт, поведенческой
дивергенции и сигнальной статистике. Поддержи флаг --seed для воспроизводимости.

Гейт: прогон 30 суток завершается, ни один вид не вымер, дисперсия черт
не упала более чем вдвое, поведенческая дивергенция когорты выросла к зрелости,
сигналы подаются и измеримо влияют на выбор цели касаткой, доля спящих
ночью никогда не достигает 100%.

Уровень нечестности сигналов может оказаться любым, включая нулевой, —
это законный исход отбора и НЕ повод подкручивать параметры (7.11).
Численность популяции НЕ настраивается напрямую: не устраивает — меняй
ёмкость среды, а не число особей.

Если баланс не сходится — подбирай константы респавна рыбы и вероятности охоты
в config/constants.yaml, каждое изменение записывай в ops/BALANCE_LOG.md
с указанием, что именно изменилось в динамике.

По завершении: отчёт в ops/reports/phase-4.md.
