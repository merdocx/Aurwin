Задача: фаза 7 «Эксплуатация» проекта Aurwin.

Прочитай docs/AURWIN_TZ.md, разделы 6.1 (блок наблюдаемости), А.7, А.9.

Реализуй:
- экспорт метрик (Prometheus) и дашборд (Grafana в docker-compose):
  популяция по видам, рождения/смерти по причинам, продолжительность жизни,
  поведенческая дивергенция, распределение навыков, метрики сигнальной системы,
  традиций и сна, метрики LLM (вызовы, стоимость, латентность, ошибки);
- алёрты из А.7 с видоспецифичными порогами: остановка тика > 2 мин,
  ошибки LLM > 50%/час, пингвины вне 10–120, касатки вне 2–12,
  расход LLM > 2x планового (~$0.40/сутки);
- systemd-юниты для sim-engine, reflection-worker, api-gateway с автостартом;
- снапшот мира не реже раза в минуту, восстановление из снапшота при рестарте,
  правило «время после паузы НЕ догоняется» (А.7);
- бэкапы Postgres (pg_dump по расписанию + WAL-архивация);
- скрипты обслуживания ретенции по расписанию;
- README по эксплуатации: как смотреть метрики, как перезапустить, как откатиться.

Гейт: перезагрузка сервера -> мир поднимается из снапшота автоматически и
продолжает тикать; алёрт срабатывает на искусственно заниженной популяции;
бэкап создаётся и восстанавливается.

По завершении: отчёт в ops/reports/phase-7.md.
